reverse-bafu · calibration benchmark · n=10 · seed 7

Four Evidence Levels

Ten real BAFU‑2026 unit processes, each turned into a synthetic “system terminated” dataset by computing its cumulative inventory. The fitter is then handed a candidate input list of deliberately varying quality and asked to recover the amounts. Because the processes are real, every true input and every true amount is known — so the optimiser can be scored directly, with no report and no model in the loop.

10 processes · 4 evidence levels · 40 fits 1,790 elementary flows per target no impact assessment whole run 45 s

The fit is the pipeline's own calibrate step. One row per elementary flow, weighted by 1/max(|target|,|model|) so a kilogram of CO₂ and a microgram of a trace metal weigh the same, then normalised per (unit, compartment) group so land use, water, radioactivity and each emission compartment carry equal weight. Columns normalised; NNLS when unbounded, BVLS when bounded. An input counts as material when its true contribution reaches 1 % of the target amount of some flow, and as chosen when its fitted contribution does — so structure is judged by the inventory, not by coefficient size.
