S3 · a top-down model built from published comparison data (UBA BAT notes)

Althaus et al. (2007), ecoinvent report No. 8, p. 764 (PDF p. 845), §85.6 and Tab. 85.3 · specs/f29ea928-… and specs/bc92bf5a-…

The last kind is the most dangerous, because it looks like the first. Titanium dioxide has a proper inventory section with tables full of numbers. But the first sentence says the inventory is based on confidential information that may not be divulged, and that what follows can be compared with minimum and maximum values across all German production sites. So transcribing those tables gives you a plausible titanium dioxide process, not this dataset. For the sulphate route the values are ranges anyway: sulphuric acid two point four to three point five, and "circa two" for the ore. Hydrogen cyanide fails in the same way: its tables describe the process from US-EPA literature, while the report says the dataset itself was built from a cumulated PlasticsEurope eco-profile. So this is S3: a top-down model built from published comparison data. No check that counts numbers can tell it apart from a transcription; someone has to read the sentence above the table. Of the five datasets we had labelled S1, only burnt shale survives these four slides.
