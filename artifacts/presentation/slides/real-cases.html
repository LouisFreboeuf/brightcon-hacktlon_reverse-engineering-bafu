Fifty-one taken all the way through, and the shape of the table is the point. Only five were transcription. Fourteen came from transferring the structure of a unit process BAFU already ships for the same product. Thirty-two — nearly two thirds — were built top-down, because that is all the evidence allowed. Be ready for a question about that split, because we corrected it late: the drafting pipeline used to stamp S1 on everything it produced, and five datasets were labelled transcription when the report had in fact given no number for some of their inputs. The rule now is traceability. If the report prints a range — sulphuric acid two point four to three point five — the calibrator only picks a point inside an interval the report set, and that is still transcription. If the report says only that an average European electricity mix is used, it has named an input and constrained nothing, and that is a model. Burnt shale is the clean case: the treeze concrete report prints the whole gate-to-gate table, and the rebuilt unit process carries essentially all of the original's mass. PMMA is the one I would defend hardest: nobody printed an inventory for it, we wrote down the methyl methacrylate polymerisation and a best-available-technology energy range, fitted the amounts, and it lands at ninety-seven percent of the mass. Two lines at the bottom. Twenty-two of the fifty-one are datasets the ecoSpold flag never told us about, so the structural test was not a footnote, it was half the result. And dis-aggregating one dataset can hand you a new dependency: nineteen of the fifty-one still terminate somewhere on an aggregate we did not reach, and eight datasets cause all nineteen. Ethylene, average, at plant alone blocks nine. That is the next morning's work, not a flaw in the method.
